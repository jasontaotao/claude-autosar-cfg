# P4 IA 重组 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Split LeftPanel into 4 independent dock panels (project/files/validation/arxml-tree), migrate DBC/ODX viewers from modals to dock panels, bump layout schema to v2.

**Architecture:** LeftPanel shell retires; its 3 tabs + Tree become standalone dock panels. Default layout has left 30% vertically split (top: project/files/validation tab group, bottom: arxml-tree). DBC/ODX viewers join a unified viewer tab group instead of opening as modals. Layout payload version bumps to 2 (P3 stored layouts fall back to default — expected).

**Tech Stack:** dockview-react@8.2.0, React 18, Zustand, Vitest, Playwright

**Spec:** docs/superpowers/specs/2026-08-30-ui-v2-workbench-design.md §6

## Global Constraints

- Final panel set (8): `project`, `files`, `validation`, `arxml-tree`, `param-editor`, `script-panel`, `dbc-viewer`, `odx-viewer`
- `left-panel` id RETIRES (never reused)
- Layout payload version: **2** (P3 v1 stored layouts silently fall back to default — expected, §9.16)
- defaultGroup `viewer` now ACTIVE for dbc-viewer/odx-viewer (P3 left it unconsumed)
- Business component props contracts unchanged (every surface = wrapper + title i18n only)
- ValidationPanel click → tree select via existing `selectedPath` store channel (no new state)
- DBC/ODX modal rendering removed from App; they render as dock panels in viewer group
- i18n three-file sync per new key
- Feature branch: p4-ia-reorg (from p3-dock-workbench)

- [ ] **Step 1: Implement new default layout builder**

Replace the P3 buildDefaultLayout with P4 version:

```ts
function buildDefaultLayout(api: DockviewApi): void {
  // Left column: tab group with project/files/validation
  api.addPanel({ id: 'project', component: 'project' });
  api.addPanel({
    id: 'files',
    component: 'files',
    position: { referencePanel: 'project', direction: 'within' },
  });
  api.addPanel({
    id: 'validation',
    component: 'validation',
    position: { referencePanel: 'project', direction: 'within' },
  });
  // Left column: arxml-tree below (vertical split)
  api.addPanel({
    id: 'arxml-tree',
    component: 'arxml-tree',
    position: { referencePanel: 'project', direction: 'below' },
  });
  // Right: param-editor
  api.addPanel({
    id: 'param-editor',
    component: 'param-editor',
    position: { referencePanel: 'project', direction: 'right' },
  });
}
```
